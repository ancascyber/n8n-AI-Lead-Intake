# Workflow Export

Place the sanitized workflow export here as `lead-intake.json`.

Before committing, replace these with placeholders:

- Owner alert "To" address (e.g. `owner@example.com`)
- Google Sheets document ID / URL (e.g. `YOUR_SHEET_ID`)
- Any other personal email address typed directly into a node

Credential secrets are not included in n8n exports, but credential names and IDs are. After importing, reconnect your own OpenAI, Gmail, and Google Sheets credentials.
